# Meet Minas

Nesse repositório você encontra os *starter files* de um projeto feito com HTML, CSS e Javascript. 

Meet Minas é uma empresa ~~fictícia~~ de viagens, especializada em viagens pelo estado de Minas Gerais. Esse projeto consiste de um site responsivo utilizando a metodologia mobile-first, ou seja, ele é desenvolvido primeiro para dispositivos mobile e depois para telas maiores.
